# Dosique

A calm, private medication reminder for Android (Flutter).

- Unlimited medicines and profiles (you, family, pets) — **100% free**
- Schedules: daily, specific weekdays, every X days, every X hours,
  as-needed (PRN) quick-log, and fixed-length courses with Day X of Y
- On-time local reminders with your choice of 5 tones, snooze 10/20/30 min
- Taken / Skip with reason / fix any past dose from the calendar history
- Stock tracking with low-stock and expiry alerts, one-tap refills
- Share today's schedule or a missed-dose summary, plus a doctor-report PDF
- Doctor/pharmacy appointments with reminders
- Large-text senior mode, dark mode, JSON backup export/import
- **No account, no ads, no paywall, no server** — all data stays on the device

Dosique is a reminder and recording tool only. It is not a medical device,
does not provide medical advice, and does not check drug interactions.

See `BUILD_ON_YOUR_PC.md` for the release build steps and
`PRIVACY_POLICY.md` for the store privacy text.
