# Dosique — build the release on your PC

Dosique is 100% free: no ads, no paywall, no account, no server. Everything
below happens on your PC — the upload key is generated by you and never
leaves your machine.

Extract the zip to **D:\App\dosique** (project root = the folder containing
`pubspec.yaml`).

> Why "Dosique"? The original working name — and the other obvious
> candidates DoseNest, PillNest, DoseDay, Dosely, Takenly and AllTaken —
> are all already taken by existing medication apps. "Dosique" had no app
> under that exact name when checked on 14 Nov 2026.
> Package: `com.dosique.app`.

## 1. Create YOUR upload key (one time only)

Open a terminal in the project root (`D:\App\dosique`) and run:

```
keytool -genkeypair -v -keystore dosique_release.jks -alias dosique -keyalg RSA -keysize 2048 -validity 10000
```

- Choose passwords when prompted and **remember them** — you need them in step 2.
- This creates `dosique_release.jks` in the project root. Keep it backed up:
  if you lose it, you cannot update the app on Google Play.

## 2. Create key.properties

1. Go to the folder `android\app\` inside the project.
2. Copy `key.properties.TEMPLATE` and rename the copy to `key.properties`.
3. Open it and replace the two placeholder passwords with the ones from step 1.
   It should look like:

```
storePassword=YOUR_KEYSTORE_PASSWORD
keyPassword=YOUR_KEY_PASSWORD
keyAlias=dosique
storeFile=../../dosique_release.jks
```

`storeFile` is relative to `android\app\`, so `../../dosique_release.jks`
points at the project root — exactly where keytool put it.

## 3. Build

```
cd D:\App\dosique
flutter pub get
flutter build apk --release
flutter build appbundle --release
```

- APK: `build\app\outputs\flutter-apk\app-release.apk` (install on your phone to test)
- AAB: `build\app\outputs\bundle\release\app-release.aab` (upload this to Play Console)

Signing is wired in `android/app/build.gradle.kts`: it reads
`android/app/key.properties` when that file exists (release signing), and
falls back to debug signing when it doesn't — so `flutter analyze` and debug
runs never crash for a missing key file.

## 4. Launcher icon

Already generated from `assets/icon/icon.png` (1024×1024) with
flutter_launcher_icons. To regenerate after changing the source:

```
dart run flutter_launcher_icons
```

## Notes for testing on your phone

- On first run, finish the 4 onboarding pages and tap **Allow reminders** —
  Android needs notification permission + exact-alarm permission for dose
  reminders to fire on time. If reminders seem late, also exclude Dosique
  from battery optimisation in your phone's Settings (some OEM skins —
  Samsung/Xiaomi/Oppo — aggressively sleep apps; exact alarms are requested,
  but OEM behaviour varies and cannot be verified from here).
- Reminders are scheduled for a rolling 14-day window and are rebuilt every
  time you open the app or change anything, and restored after a reboot by
  the boot receiver.
- Everything is stored on the phone only. Use **More → Backup → Export**
  before switching phones, and **Import** on the new phone.
